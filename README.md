# Coin DS Buy Gold Flow

A React Native Web preview of a two-screen buy-gold flow built with Coin components from [`jfs-components`](https://www.npmjs.com/package/jfs-components).

## Screens

- Gold product overview
- Payment amount and bank account confirmation

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The live preview is deployed automatically through GitHub Pages.
